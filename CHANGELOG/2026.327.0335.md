# 2026.327.0335 — feat(task): cue-gen regenerates the params from the schema with spec's generator, by ref

## Summary

This repo's `params/cue_types_gen.go` is generated from `schema/builder.cue`, but there was **no way to run the generation here** — no `task:`, no script, no workflow (`charly task cue-gen` reported `unknown task "cue-gen" (declared tasks: )`). So the generated file could not be kept in step, and the only way to produce it was to copy spec's pipeline into this repo (opencharly/plugin-builder#10).

- **`charly task cue-gen` now exists here, and it runs spec's ONE generator BY REF**: `go run github.com/opencharly/spec/schemagen@v0.2026327.329` — the merged release of opencharly/spec#425, which moved the generator to that module's root so another module can run it. Nothing is copied into this repo.
- **The second step is the drift gate**: after regeneration, the committed file must show no diff. A stale committed `cue_types_gen.go` therefore FAILS the task, with the message telling the author to commit the regenerated file.
- **The tag is a merged release, never a branch** — a version-less ref would fall to the mutable default and defeat reproducibility.
